# Vellbyte company website

Static site generated by `build.py`. Requirements: Python 3.11 or later. No package install, server-side runtime, form backend, JavaScript, cookies, or analytics library is included.

```
python build.py
python -m http.server 8765 --bind 127.0.0.1
python verify.py
python verify_live.py
```

Change shared text, metadata, navigation, or product content in `build.py`; change the responsive design in `assets/site.css`; run `build.py` after edits. Generated HTML is committed for a standard static host. Paths are site-root-relative: deploy the contents at the root of vellbyte.com, not under a repository subpath. Update the canonical `SITE` constant only if the production hostname changes. `assets/share.png` is the branded 1200 × 630 sharing preview.

The product images are unmodified emulator screenshots from the Trip Split and Pack Planner signed Android release builds, using fictional sample data. The launch records document their source and the Pack Planner emulator APK checksum. No store release is claimed or linked.

The public site links to the HTTPS support subdomain. The `/support/` directory is a retained mirror of support-site content at commit `f7b284c406680b3919cc67f7d42beb2a700854fc`; the mirrored app-specific disclosures are drafts and are not final policies. Keep the mirror in sync when appropriate and verify support links when updating them. Contact and support addresses have received delivery tests; sending as the support alias has not been verified. The testing email link is an inquiry, not enrollment, and the services email link is a project inquiry, not a quote or agreement. `verify_live.py` checks trusted HTTPS responses for company and support routes, including the www redirect; it does not test social-network access or mailbox delivery.

The website privacy page describes only this static implementation. Review that copy against the actual production hosting, analytics, and any future site features whenever those change.
